# Deye Pulse — окремий Telegram-бот

Це серверний бот, незалежний від Android-додатка. Працює в особистому чаті власника. Читає Deye Cloud; команд керування інвертором немає.

- Одне повідомлення-дашборд з автоматичним редагуванням щохвилини та кнопкою оновлення.
- SOC, напруга і потужність АКБ, споживання, напруга/стан/потужність мережі, сонячна генерація.
- Каталог усіх доступних параметрів API, сторінки по 12 показників; відсутні значення позначені.
- Історія до 288 різних вимірів, журнал до 100 подій.
- Сповіщення про відключення/повернення мережі, низький SOC, високе споживання без мережі, втрату свіжих даних.
- Пороги й пауза сповіщень налаштовуються кнопками в Telegram. Налаштування Android не змінюються.

## Команди

`/dashboard`, `/status`, `/battery`, `/grid`, `/solar`, `/parameters`, `/events`, `/settings`, `/help`.

## Розгортання

Node 24, один Vercel Daemon `deye-bot` у `fra1` з 1 GiB пам'яті та приватний Vercel Blob у тому самому регіоні. Секрети — тільки encrypted environment variables. `TELEGRAM_CHAT_ID` — ID особистого чату власника. На старті бот відмовляється працювати, якщо для токена вже встановлено webhook; чужий webhook не видаляє.

`vercel.json` містить один екземпляр після перевірки доступів і стану. Зупинка: змінити `instances.fra1` на `0` і опублікувати production deployment. Попередній процес завершується за SIGTERM, новий чекає 35 с перед початком опитування. Усі записи стану мають ETag-умову: конфлікт завершує процес замість перезапису чужого стану.

Адміністративна функція `POST /api/admin` вимагає `Authorization: Bearer ADMIN_SECRET`. Порожнє тіло перевіряє читання API; `{"action":"open"}` створює дашборд у дозволеному чаті та меню команд. На публічному сайті телеметрія й доступи відсутні.

## Ліміти хостингу

Станом на 27.11.2026 Vercel Daemons Hobby має 420 GB-hours provisioned memory на місяць для всієї команди. Один процес 1 GiB вичерпує цей ліміт приблизно за 17.5 діб; CPU та Blob також мають квоти. **Це не безлімітний безкоштовний 24/7 хостинг.** На Pro застосовується оплата використання; тариф самостійно не змінюється. Перед постійним запуском потрібно обрати достатній тариф/сервер. Документація: https://vercel.com/docs/daemons/limits

## Перевірки

`npm ci` та `npm test`. Тести використовують локальні заглушки, не надсилають реальних повідомлень і не викликають команд інвертора.

Мережа підтверджується через 30 с після першого свіжого спостереження без очікування наступного timestamp логера. Опитування не прискорює фізичну передачу даних логером у Deye Cloud. Офлайн, застарілі, майбутні та відсутні значення не інтерпретуються як відключення.

Черга сповіщень зберігається до доставки, повторюється після мережевої помилки, поважає Telegram retry_after, відкидає події старші 24 годин. Доставка щонайменше один раз: збій між успішною відправкою Telegram і записом підтвердження може повторити подію. При недоступності сховища роботу слід відновити до очікування гарантій доставки.
